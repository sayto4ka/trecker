# Трекер привычек (PySide6)

Приложение на Python + PySide6, повторяющее макет нового дизайна. Всё
приложение — **одно окно**: переходы между экранами происходят через
переключение внутри окна (QStackedWidget), отдельные окна/диалоги не
используются.

## Экраны и переходы

- **Онбординг** (только при первом запуске) — ввод имени → сразу переходит
  на главный экран, больше не показывается.
- **Главный экран** — приветствие по времени суток, мини-карточка «Ближайшие
  задачи» (клик → полный список), недельная полоска дат, две большие кнопки
  «Мои привычки» и «Добавить привычку» (ведут на соответствующие экраны).
- **Мои привычки** — список с чекбоксом, `+1` для целей больше 1, удаление.
  Кнопка «←» возвращает на главный экран.
- **Добавить привычку** — встроенная форма (не всплывающее окно): название,
  иконка, цель в день, единица измерения, необязательное напоминание.
  После сохранения переходит на «Мои привычки».
- **Ближайшие задачи** — список невыполненных сегодня привычек с
  напоминанием и временем.
- **Настройки** — переключатель уведомлений, переход на «Темы приложения»,
  выбор размера шрифта (S/M/L).
- **Темы приложения** — 5 цветов темы (розовый, зелёный, бирюзовый, жёлтый,
  фиолетовый); тема выбирается случайно раз в день, экран показывает, какая
  активна сейчас.
- Нижняя навигация (Home / Ближайшие задачи / Настройки) видна на основных
  экранах.

Все данные (привычки, имя, настройки) хранятся локально в
`~/.habit_tracker/habits.json` и сохраняются между запусками.

## Установка и запуск

```bash
pip install -r requirements.txt
python main.py
```

Требуется Python 3.9+.

## Структура проекта

- `models.py` — модель `Habit`, хранилище `HabitStore` (привычки + настройки
  пользователя + случайный выбор темы дня).
- `widgets.py` — переиспользуемые виджеты: верхняя панель с кнопкой назад,
  недельная полоска, карточки привычек и напоминаний, форма добавления
  привычки, элементы настроек, строки палитры тем, нижняя навигация.
- `main.py` — главное окно и все экраны (`QStackedWidget`), логика переходов
  между ними без создания дополнительных окон.
